# CLOC Trends

A collection of disjointed tools to run scc on random git repositories and generate useless (but fun) graphs and plots.

> The project name pays respect to [cloc](https://github.com/AlDanial/cloc), the original tool this was built around. We've since switched to [scc](https://github.com/boyter/scc) for speed, but the name stuck.
